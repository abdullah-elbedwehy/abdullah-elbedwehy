## 🚀 Projects

### [ReelRadar](https://reelradar-app.vercel.app/) — Chrome Extension
Sort and filter Instagram Reels and TikTok by 6 engagement metrics (views, likes, comments, shares, saves, date) — fully client-side, no account needed. One-click CSV/XLSX export via SheetJS.
`Vanilla JS` `Chrome MV3` `React` `Vite`

### [CF++](https://github.com/abdullah-elbedwehy/codeforces-plus-plus) — Codeforces++ Extension
Turns Codeforces problem pages into a mini in-browser IDE using Monaco Editor. Keyboard navigation, bookmarking with CSV export, one-click AI explanations, and a polished dark-mode UI.
`JavaScript` `Monaco Editor` `Tampermonkey`

### [Promptful](https://github.com/abdullah-elbedwehy/Promptful-prompt-management-app) — AI Prompt Management Platform
Full-stack app to organise AI prompts with dynamic templates, variable support, multi-model compatibility (ChatGPT, Claude), full-text search, tagging, and version control.
`React` `TypeScript` `Flask` `SQLite` `Tailwind` `Docker`
